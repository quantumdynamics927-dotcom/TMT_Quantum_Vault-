# TMT Quantum Vault - Hugging Face Spaces Deployment

This folder contains the static web assets for the TMT Quantum Vault documentation site deployed on Hugging Face Spaces.

## Deployment

The site is automatically deployed from the main branch of the repository.

## Local Development

To view the site locally, simply open `index.html` in a web browser or use a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Structure

- `index.html` - Main documentation page
- `dashboard.js` - Interactive dashboard
- `research-status.html` - Research status page
- `docs/` - Additional documentation
