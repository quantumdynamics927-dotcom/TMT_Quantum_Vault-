## Classification Rules

### Core-13 Admission Rule
An agent belongs in the **coordination core** only if it contributes directly to:
- **Cognition** — strategic analysis, information processing
- **Perception** — monitoring, pattern recognition
- **Synthesis** — knowledge fusion, integration
- **Resonance** — frequency tuning, harmonic stabilization
- **Self-modeling** — integration evolution, reflection
- **Biological encoding** — DNA/biological interface
- **Pattern extraction** — fractal generation, self-similar structures
- **Global coordination** — network orchestration

### Operational Support Layer Admission Rule
An agent belongs in the **operational support layer** if it mainly performs:
- **Audit** — compliance verification
- **Storage** — memory persistence, provenance
- **Workflow control** — process orchestration
- **Safety** — integrity verification, protection

**Key Principle:** Low Φ-score does NOT exclude an agent from the core. The question is whether the agent's **role is archetypal (ontological) or operational (infrastructure).**
