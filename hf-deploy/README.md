## Usage

### Orchestration Demo

1. Select a **Task Type** (synthesis, coordination, routing, etc.)
2. Enter an **Objective** describing the task
3. Choose **Simulation** mode (safe for HF Spaces)
4. Click **Run Orchestration** to see agent coordination

### Benchmark

Run the 19-task benchmark suite to validate orchestration behavior across:
- Routing tasks
- Delegation chains
- Conflict resolution
